# Road of the Horde — Three.js / Yandex Games

Полностью переделанный 3D-прототип без Unity. Используется Three.js/WebGL, процедурные 3D-модели и WebAudio, поэтому проект не требует внешних картинок и оставляет `music/` пустой.

## Запуск

Откройте `index.html` через web-сервер. Для Яндекс Игр загрузите содержимое архива как HTML5-игру.

Для локального теста лучше использовать любой static server, потому что браузер может ограничивать некоторые функции при `file://`.

## Реализовано

- Three.js 3D WebGL-сцена.
- Перспективная камера, пустынная трасса, песок, кактусы, машины.
- 3D армия с процедурными солдатами, построением и бегом.
- Управление свайпом/мышью влево-вправо.
- Ворота `+2`, `+3`, `+5`, `x2`, `-2`.
- Оружие и автоматическая стрельба.
- Зомби, урон, смерть и частицы.
- Большой 3D-босс с HP-баром.
- Волны.
- Процедурная музыка и SFX через WebAudio; папка `music/` пустая.
- Yandex Games SDK с автоинициализацией.
- `LoadingAPI.ready()`.
- `GameplayAPI.start()` / `GameplayAPI.stop()`.
- Fullscreen ad с `onOpen`, `onClose`, `onError`.
- Пауза и mute на рекламе.
- Пауза при blur/visibilitychange и `game_api_pause`.
- Возврат звука после resume.
- `FixLongTap.css` присутствует и подключается до игрового JS.

## Важное замечание

Three.js подключён из CDN в `index.html`. Если площадка требует полностью автономный архив без внешних сетевых зависимостей, положите локальную копию `three.min.js` в проект и замените соответствующий `<script src=...>`.
